현서의 글방 - 사용 설명서
==========================

인터넷 연결 없이 쓰는 가벼운 워드프로세서입니다. 한글과 영어를 모두 쓸 수 있습니다.

■ 실행
  - 바탕 화면 또는 시작 메뉴의 '현서의 글방'을 누릅니다.
  - docx/doc 파일을 오른쪽 클릭 → [연결 프로그램] → '현서의 글방'을 고르면 그 파일이 바로 열립니다.
  - 화면은 Microsoft Edge(없으면 Chrome)의 별도 창으로 뜹니다. 인터넷에는 연결하지 않습니다.

■ 열 수 있는 파일
  .docx, .doc(Word 97-2003), .rtf, .txt, .html

■ 저장할 수 있는 형식
  .docx  (권장) 최신 Word, 한컴오피스, 구글 문서 등에서 열립니다.
  .doc   Word가 열 수 있는 HTML 기반 호환 형식입니다. 그림이 있으면 docx를 권장합니다.
  .txt   서식 없이 글자만 저장합니다.

■ 자주 쓰는 단축키
  Ctrl+S 저장 / Ctrl+Shift+S 다른 이름으로 저장 / Ctrl+O 열기 / Ctrl+P 인쇄(PDF 저장 가능)
  Ctrl+B 굵게 / Ctrl+I 기울임 / Ctrl+U 밑줄 / Ctrl+Z 실행 취소 / Ctrl+Y 다시 실행
  Ctrl+F 찾기 / Ctrl+H 바꾸기 / Ctrl+K 링크 / Ctrl+Enter 쪽 나누기
  Tab / Shift+Tab : 목록 들여쓰기·내어쓰기, 표에서 다음/이전 칸

■ 알아둘 점
  - 저장하지 않고 창을 닫으면, 다음에 실행할 때 복구할지 물어봅니다.
  - '연결 프로그램'으로 연 파일을 처음 저장할 때는 저장 위치를 한 번 골라 주세요.
  - 머리글/바닥글, 각주, 변경 내용 추적, 맞춤법 검사는 지원하지 않습니다.

■ 제거
  Windows 설정 → 앱 → 설치된 앱(앱 및 기능)에서 '현서의 글방'을 제거합니다.
