# LiteWord — 인터넷 없이 쓰는 가벼운 워드프로세서

`LiteWord.html` 파일 하나(약 200KB)로 동작하는 문서 편집기입니다.
설치가 필요 없고, 인터넷 연결 없이 쓸 수 있으며, Word 문서(.docx / .doc)를 열고 저장할 수 있습니다.
한글과 영어를 모두 쓸 수 있습니다.

## 실행 방법

| 방법 | 설명 |
| --- | --- |
| `LiteWord.html` 더블클릭 | 기본 브라우저에서 열립니다. **Chrome 또는 Edge를 권장**합니다. |
| `LiteWord-AppWindow.bat` 더블클릭 (Windows) | 주소창 없는 독립된 프로그램 창으로 엽니다 (Edge → Chrome 순서로 찾음). |

- 폴더째 USB 등에 복사해서 어느 PC에서나 쓸 수 있습니다.
- 외부 서버나 인터넷 자료를 전혀 불러오지 않습니다. 문서는 내 PC에서만 처리됩니다.

## 지원 형식

| 형식 | 열기 | 저장 |
| --- | --- | --- |
| **.docx** (Word 2007 이상) | ✅ 글자·문단 서식, 제목, 목록, 표(병합 셀), 그림, 링크, 쪽 나누기 | ✅ (권장 형식) |
| **.doc** (Word 97-2003) | ✅ 글자·문단 서식, 제목, 목록, 표(병합 셀), 본문 안 그림, 링크, 쪽 나누기 | ✅ Word가 여는 HTML 기반 호환 형식 ※ |
| .rtf | ✅ | – |
| .txt | ✅ (UTF-8, EUC-KR/CP949 자동 인식) | ✅ (UTF-8) |
| .html / .htm / .mht | ✅ | – |

※ `.doc` 저장은 정식 Word 97-2003 이진 형식이 아니라, Word·한컴오피스·LibreOffice가 `.doc`로 열 수 있는
HTML 기반 형식입니다. 그림이 있는 문서나 서식을 정확히 유지해야 하는 문서는 **.docx로 저장**하세요.

## 주요 기능

- 문단 스타일(본문, 제목 1~4), 글꼴(맑은 고딕, 굴림, 돋움, 바탕, 궁서, 나눔글꼴, Arial, Times New Roman 등), 글자 크기
- 굵게·기울임·밑줄·취소선·위/아래 첨자, 글자 색, 형광펜, 서식 지우기
- 왼쪽/가운데/오른쪽/양쪽 맞춤, 줄 간격(1.0~3.0), 글머리 기호·번호 목록, 들여쓰기
- 표 삽입(마우스로 크기 선택), 행/열 추가·삭제, 표 안에서 Tab으로 다음 칸 이동
- 그림 삽입(파일 선택·붙여넣기·끌어 놓기), 그림 크기 조절(클릭 후 25/50/75/100%)
- 링크, 쪽 나누기, 찾기/바꾸기, 인쇄 및 PDF 저장(인쇄 대화상자에서 "PDF로 저장")
- 글자 수(공백 포함/제외)·단어 수 표시, 확대/축소
- 저장하지 않고 창을 닫았을 때 다음 실행 시 **자동 복구**
- 파일을 창에 끌어 놓아서 열기
- Chrome·Edge에서는 연 파일에 바로 덮어쓰기 저장(Ctrl+S). 다른 브라우저에서는 '다운로드' 폴더에 저장됩니다.

## 단축키

| 키 | 기능 | 키 | 기능 |
| --- | --- | --- | --- |
| Ctrl+S | 저장 | Ctrl+Shift+S | 다른 이름으로 저장 |
| Ctrl+O | 열기 | Ctrl+P | 인쇄 |
| Ctrl+B / I / U | 굵게 / 기울임 / 밑줄 | Ctrl+Z / Y | 실행 취소 / 다시 실행 |
| Ctrl+L / E / R / J | 왼쪽 / 가운데 / 오른쪽 / 양쪽 맞춤 | Ctrl+K | 링크 |
| Ctrl+F / H | 찾기 / 바꾸기 | Ctrl+Enter | 쪽 나누기 |
| Tab / Shift+Tab | 목록 들여쓰기·내어쓰기, 표에서 다음/이전 칸 | Ctrl+클릭 | 링크 열기 |

## 알아둘 점

- 기본 수준의 편집기입니다. 머리글/바닥글, 각주, 변경 내용 추적, 메모, 글상자 배치, 맞춤법 검사는 지원하지 않습니다.
  (불러온 문서의 글상자 내용은 일반 문단으로 표시됩니다.)
- 화면은 A4 폭의 한 장으로 이어서 보여 줍니다. 실제 쪽 나눔은 인쇄할 때 정해지며, 상태 표시줄의 쪽 수는 추정값입니다.
- .doc 파일 중 아주 오래된 Word 95 이하 형식과 암호가 걸린 문서는 열 수 없습니다. 떠 있는(배치된) 그림은 가져오지 않습니다.
- 표시되는 글꼴은 PC에 설치된 글꼴을 따릅니다. 설치되지 않은 글꼴은 비슷한 글꼴로 보입니다.

## 개발자용

소스는 `src/`에 나뉘어 있고, `build.py`가 하나의 `LiteWord.html`로 묶습니다.

```bash
python3 build.py          # src/ → LiteWord.html
bash tests/run-all.sh     # 자동 테스트 (Node.js + Playwright + Chromium, 샘플 변환에는 python-docx·LibreOffice 필요)
```

| 파일 | 역할 |
| --- | --- |
| `src/index.html`, `src/styles.css` | 화면 구성과 스타일 |
| `src/editor.js`, `src/app.js` | 편집 명령, 표·그림·링크, 파일 열기/저장, 찾기, 자동 복구 |
| `src/zip.js` | ZIP 읽기/쓰기 (브라우저 내장 압축 사용) |
| `src/docx-import.js`, `src/docx-export.js`, `src/model.js` | .docx 읽기/쓰기 |
| `src/doc-import.js` | .doc (Word 97-2003 이진 형식) 읽기 |
| `src/rtf-import.js`, `src/html-io.js` | .rtf 읽기, HTML 정리·붙여넣기, HTML 기반 .doc 저장 |
