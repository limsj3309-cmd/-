# PDF 편집기 (개인용, Windows)

PDF 뷰어 + 압축 + 드래그 방지 변환 + 페이지 편집(순서 변경, 회전, 삭제) + 분할 + 병합.

## 설치 파일 받기

1. GitHub 저장소의 **Actions** 탭으로 이동
2. **PDF 편집기 윈도우 빌드** 실행 기록 중 가장 최근(초록색 체크) 항목 클릭
3. 맨 아래 **Artifacts**에서 `PdfEditor-Setup-x.y.z` 다운로드 → 압축 풀기 → `PdfEditor-Setup-x.y.z.exe` 실행

- 관리자 권한 없이 설치됩니다 (현재 사용자 전용).
- 코드 서명이 없어서 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면
  **추가 정보 → 실행**을 누르세요.
- 설치 중 "PDF 파일 오른쪽 메뉴 '연결 프로그램'에 추가"를 선택하면
  PDF 파일을 마우스 오른쪽 버튼 → 연결 프로그램 → PDF 편집기로 열 수 있습니다.
  (기본 PDF 프로그램은 바꾸지 않습니다.)

## 기능

| 기능 | 사용 방법 | 설명 |
|---|---|---|
| 뷰어 | 파일을 창에 끌어다 놓기 / `Ctrl+O` | 왼쪽 썸네일, 가운데 본문. `Ctrl+마우스 휠`로 확대/축소, `Ctrl+0` 폭 맞춤 |
| 순서 변경 | 왼쪽 썸네일을 드래그 / `Ctrl+↑` `Ctrl+↓` | 여러 장 선택(`Ctrl`/`Shift`+클릭) 후 한 번에 이동 가능 |
| 회전 | `Ctrl+L`(왼쪽) / `Ctrl+R`(오른쪽) | 선택한 페이지만 회전 |
| 삭제 | `Delete` | 선택한 페이지 삭제 |
| 실행 취소 | `Ctrl+Z` / `Ctrl+Y` | 저장 전까지 모든 편집 되돌리기 가능 |
| 저장 | `Ctrl+S` / `Ctrl+Shift+S` | 편집 내용 반영 |
| 압축 | 도구 → 압축 | **약**(200dpi) / **중**(150dpi) / **강**(100dpi). 글자는 그대로 유지 |
| 드래그 방지 | 도구 → 드래그 방지 | 페이지를 이미지로 바꿔 글자 선택·복사·검색 불가 |
| 분할 | 도구 → 분할 | 범위별(`1-3, 5, 8-`) / N페이지씩 / 한 페이지씩 / 선택 페이지만 추출 |
| 병합 | 도구 → 병합, 또는 여러 파일을 창에 한꺼번에 끌어다 놓기 | 순서 조정, 파일별 책갈피 자동 생성 |

압축·드래그 방지·분할은 **현재 편집 중인 상태**(순서·회전·삭제 반영)를 기준으로 동작하고,
결과는 항상 **새 파일**로 저장합니다(원본은 그대로).

### 드래그 방지 변환이 용량을 최소화하는 방법

모든 페이지를 이미지로 바꾸고, 페이지마다 아래 방식 중 **가장 작은 것**을 자동으로 고릅니다.

- 흑백 문서 페이지 → **16단계 회색 PNG(4비트)**: 글자가 선명하면서 가장 작음
- 흑백 사진 페이지 → 회색 JPEG
- 컬러 문서(도표 등) → 64색 팔레트 PNG 또는 JPEG 중 작은 쪽
- 컬러 사진 → JPEG

PNG 압축 데이터는 PDF에 **다시 압축하지 않고 그대로** 넣어서 일반적인 방식보다 약 40% 더 작습니다.

테스트 결과 (한글 텍스트 5페이지, 150dpi):

| 방식 | 용량 |
|---|---|
| 글자를 도형(벡터)으로 변환 | 1,485 KB |
| 일반 JPEG 이미지화 | 1,281 KB |
| **이 프로그램** | **451 KB** |

※ 원래 글자로 된 PDF는 이미지로 바뀌면서 용량이 늘 수 있습니다.
더 작게 하려면 선명도를 '최소 용량'으로 선택하세요.
※ OCR(문자 인식)로 글자를 다시 읽어내는 것까지는 막을 수 없습니다.

## 개발

```bash
cd pdf_tool
pip install -r requirements-build.txt
python main.py                 # 실행
python -m pytest -q            # 테스트 (화면 없는 환경: QT_QPA_PLATFORM=offscreen)
```

윈도우 PC에서 직접 설치 파일을 만들려면 Python 3.13과 [Inno Setup 6](https://jrsoftware.org/isdl.php)을
설치한 뒤 `build_windows.bat`을 실행하세요. 결과: `dist\PdfEditor-Setup-x.y.z.exe`

### 구조

```
pdf_tool/
├── main.py                 실행 진입점 (--selftest: 빌드 검증)
├── pdftool/
│   ├── core.py             PDF 처리 로직 (UI와 분리, 단독 테스트 가능)
│   └── ui/
│       ├── main_window.py  메인 창, 메뉴/툴바, 각 기능 흐름
│       ├── viewer.py       본문 뷰어 (보이는 페이지만 렌더링)
│       ├── thumbnails.py   썸네일 목록 (드래그로 순서 변경)
│       ├── dialogs.py      압축/드래그 방지/분할/병합 설정 창
│       └── worker.py       백그라운드 작업 + 진행률/취소
├── tests/                  core 테스트 + 화면 없이 UI 조작 테스트
├── installer/
│   ├── pdftool.spec        PyInstaller 설정
│   ├── setup.iss           Inno Setup 설치 파일 설정
│   └── make_icon.py        아이콘 생성
└── build_windows.bat       윈도우 PC에서 직접 빌드
```

빌드 자동화: `.github/workflows/pdf-tool-windows.yml`
(테스트 → exe 생성 → exe 자체 점검 → 설치 파일 생성 → 무인 설치 후 다시 점검)

### 라이선스 참고

PDF 엔진 PyMuPDF는 AGPL 라이선스입니다. 개인 사용에는 문제가 없지만,
이 프로그램을 외부에 배포하거나 판매하려면 소스 공개 또는 상용 라이선스가 필요합니다.
