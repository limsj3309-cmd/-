# 문서뷰어 (DocViewer)

갤럭시(안드로이드 8.0 이상)용 가벼운 문서 뷰어입니다. 외부 라이브러리 없이 각 문서 형식을 직접 해석하기 때문에 설치 파일이 **약 85KB**입니다.

## 설치

1. 저장소 루트의 `release/DocViewer-v1.1.apk` 파일을 휴대폰으로 옮깁니다 (카카오톡 나에게 보내기, 구글 드라이브, USB 등).
2. 휴대폰에서 APK 파일을 누릅니다.
3. "출처를 알 수 없는 앱 설치" 허용을 묻는 화면이 나오면 해당 앱(내 파일, 크롬 등)에 대해 **허용**을 켭니다.
4. **설치**를 누릅니다.

## 지원 형식

| 종류 | 확장자 | 표시 방식 |
|---|---|---|
| PDF | pdf | 안드로이드 내장 PDF 엔진으로 페이지를 그림으로 표시 (필요한 페이지만 그때그때 렌더링) |
| 워드 | docx, doc | 글자 서식·표(병합 셀)·그림·목록·각주·차트 / doc는 글자와 표 |
| 엑셀 | xlsx, xls | 시트 탭, 숫자·날짜 서식, 병합 셀, 글꼴·배경색 (시트당 최대 5,000행) |
| 파워포인트 | pptx, ppt | 슬라이드 레이아웃 그대로(도형·그림·표·차트·SmartArt) / ppt는 슬라이드 글자 |
| 한글 | hwp, hwpx | 글자 서식·문단 정렬·표(병합 셀)·그림·글상자, 배포용 문서 포함 |

## 사용법

- 앱을 열고 **문서 열기**를 누르거나,
- 내 파일·카카오톡·이메일 등에서 문서를 누른 다음 **문서뷰어**를 선택합니다.
- 메뉴: 찾기, 글자 크기, 다른 앱으로 열기, 공유
- 두 손가락으로 확대/축소할 수 있습니다.
- 워드·한글 문서는 기본으로 원본 페이지 모양 그대로 보여주고, 메뉴의 **모바일 맞춤 보기**를 켜면 화면 폭에 맞춰 글자를 다시 배치합니다.

## 안정성

- 문서는 백그라운드에서 해석하고, 손상된 파일이나 지원하지 않는 파일은 앱이 종료되지 않고 안내 메시지를 보여줍니다.
- 문서는 기기 안에서만 처리되며, 문서 화면에서 외부 서버로 나가는 요청은 모두 차단됩니다.
- 지원하지 않는 것: 암호가 걸린 문서, 한글 97 이하 / Word·Excel 95 이하 형식.

## 직접 빌드

```
cd DocViewer
./gradlew assembleRelease
# 결과: app/build/outputs/apk/release/app-release.apk
```

Android SDK 경로는 `local.properties`의 `sdk.dir`로 지정합니다. 앱 업데이트 때 같은 서명을 쓰도록 서명 키(`keystore/docviewer.jks`)도 저장소에 함께 들어 있습니다.
