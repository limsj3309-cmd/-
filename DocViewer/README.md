# 문서뷰어 (DocViewer)

갤럭시(안드로이드 8.0 이상)용 가벼운 문서 뷰어입니다. 외부 라이브러리 없이 각 문서 형식을 직접 해석하기 때문에 설치 파일이 **약 85KB**입니다.

## 설치

**휴대폰에서 아래 링크를 누르면 바로 내려받습니다 (항상 최신 버전, 현재 v1.3):**

https://github.com/limsj3309-cmd/-/raw/claude/sharp-goldberg-a6h052/release/DocViewer.apk

1. 위 링크를 휴대폰 브라우저(크롬, 삼성 인터넷)에서 엽니다. 또는 저장소 루트의 `release/DocViewer.apk`를 카카오톡 나에게 보내기·구글 드라이브·USB로 옮깁니다.
2. 다운로드가 끝나면 알림이나 '내 파일 > 다운로드'에서 APK를 누릅니다.
3. "출처를 알 수 없는 앱 설치" 허용을 묻는 화면이 나오면 해당 앱(크롬, 내 파일 등)에 대해 **허용**을 켭니다.
4. **설치**를 누릅니다.

> v1.1 이하를 설치했다면 **기존 앱을 먼저 삭제**한 뒤 설치하세요(v1.2 이상은 그대로 덮어 설치하면 됩니다). 보안을 위해 앱 서명 키를 새로 바꿨기 때문입니다.

## 지원 형식

| 종류 | 확장자 | 표시 방식 |
|---|---|---|
| PDF | pdf | 안드로이드 내장 PDF 엔진으로 페이지를 그림으로 표시 (필요한 페이지만 그때그때 렌더링) |
| 워드 | docx, doc | 글자 서식·표(병합 셀)·그림·목록·각주·차트 / doc는 글자와 표 |
| 엑셀 | xlsx, xls | 시트 탭, 숫자·날짜 서식, 병합 셀, 글꼴·배경색 (시트당 최대 5,000행) |
| 파워포인트 | pptx, ppt | 슬라이드 레이아웃 그대로(도형·그림·표·차트·SmartArt) / ppt는 슬라이드 글자 |
| 한글 | hwp, hwpx | 글자 서식·문단 정렬·표(병합 셀)·그림·글상자, 배포용 문서 포함 |

## 사용법

- 앱을 열고 **문서 열기**를 누르거나,
- 내 파일·카카오톡·이메일 등에서 문서를 누른 다음 **문서뷰어**를 선택합니다.
- 메뉴: 찾기, 글자 크기, **다운로드 폴더에 저장**, 다른 위치에 저장, 다른 앱으로 열기, 공유
- 카카오톡·메일에서 연 문서는 임시 파일이라 앱을 닫으면 사라집니다. **다운로드 폴더에 저장**을 누르면 원본 파일 그대로 휴대폰의 `Download` 폴더에 남습니다(저장 권한 요청 없음, 안드로이드 8~9는 저장 위치를 직접 고릅니다).
- 두 손가락으로 확대/축소할 수 있습니다.
- 워드·한글 문서는 기본으로 원본 페이지 모양 그대로 보여주고, 메뉴의 **모바일 맞춤 보기**를 켜면 화면 폭에 맞춰 글자를 다시 배치합니다.

## 안정성과 보안

- 문서는 백그라운드에서 해석하고, 손상된 파일이나 지원하지 않는 파일은 앱이 종료되지 않고 안내 메시지를 보여줍니다.
- 문서는 기기 안에서만 처리됩니다. 문서 화면은 외부로 나가는 요청을 모두 막고, 콘텐츠 보안 정책(CSP)으로 앱 자체 스크립트 말고는 어떤 스크립트도 실행되지 않습니다.
- 문서 안의 링크는 사용자가 직접 누르고 확인 창에서 **열기**를 골랐을 때만 브라우저로 열립니다(웹·메일·전화 링크만 허용).
- 악성 파일 방어: XML 엔티티 폭탄(DTD)은 거부합니다. 압축 폭탄이나 지나치게 크거나 깊은 문서는 크기·개수·깊이 제한으로 막습니다. 엑셀 병합 셀 남용처럼 작은 파일로 처리를 오래 붙잡는 경우도 상한을 둡니다. 열 수 있는 파일은 최대 500MB, PDF는 앞쪽 3,000쪽까지 표시합니다.
- 다른 앱이 `file://` 경로를 넘겨 이 앱 내부 파일을 읽게 하는 경로를 막았습니다(시스템이 주는 `content://` 문서만 엽니다).
- 최근 목록에서 지운 문서는 장기 접근 권한도 반납합니다. 최근 문서 목록과 임시 파일은 클라우드 백업이나 새 기기 이전에 포함되지 않습니다. Safe Browsing URL 확인과 WebView 사용 통계 전송도 끕니다.
- 지원하지 않는 것: 암호가 걸린 문서, 한글 97 이하 / Word·Excel 95 이하 형식.

## 직접 빌드

```
cd DocViewer
./gradlew assembleRelease
# 결과: app/build/outputs/apk/release/app-release.apk
```

Android SDK 경로는 `local.properties`의 `sdk.dir`로 지정합니다.

### 릴리스 서명

서명 키는 저장소에 **넣지 않습니다**. `DocViewer/keystore.properties`(git 제외)에 아래처럼 적거나, 같은 값을 환경 변수 `DOCVIEWER_STORE_FILE`, `DOCVIEWER_STORE_PASSWORD`, `DOCVIEWER_KEY_ALIAS`, `DOCVIEWER_KEY_PASSWORD`로 넘깁니다. 둘 다 없으면 서명되지 않은 APK가 만들어집니다.

```
storeFile=signing/docviewer-release.jks
storePassword=...
keyAlias=docviewer
keyPassword=...
```

앱을 업데이트하려면 항상 같은 키로 서명해야 합니다. 키 파일과 비밀번호는 따로 안전하게 보관하세요.
